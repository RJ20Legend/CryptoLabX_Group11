# ATM Security Test Cases

## TC01 - Valid Login
Expected: Login succeeds with valid credentials.

## TC02 - Invalid Login
Expected: Invalid credentials are rejected.

## TC03 - Balance Inquiry
Expected: Correct balance is displayed.

## TC04 - Valid Deposit
Expected: Valid deposit increases balance.

## TC05 - Negative Deposit
Expected: Negative deposit is rejected.

## TC06 - Zero Deposit
Expected: Zero deposit is rejected.

## TC07 - Valid Withdrawal
Expected: Valid withdrawal decreases balance.

## TC08 - Withdrawal Greater Than Balance
Expected: Withdrawal is rejected.

## TC09 - Negative Withdrawal
Expected: Negative withdrawal is rejected.

## TC10 - Invalid Input
Expected: Invalid input is handled safely.

## TC11 - PIN Change
Expected: Valid PIN change succeeds.

## TC12 - Invalid PIN Change
Expected: Invalid PIN change is rejected.
